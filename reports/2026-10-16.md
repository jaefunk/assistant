## Python

- **Python 3.15 정식 출시:** Python 3.15가 2026년 10월 9일 출시되었고, 지연 임포트, `frozendict`·`sentinel` 내장 타입, 기본 UTF-8 인코딩, 개선된 실험적 JIT, free-threaded 빌드용 안정 ABI 등이 포함되었으며, uv 0.13.0은 3.15를 기본 다운로드 버전으로 바꿨습니다.
- **3.15 성능 벤치마크:** Miguel Grinberg의 측정에서는 3.15 표준 인터프리터가 3.14와 비슷했지만 실험적 JIT 빌드는 약 20~28% 빨랐고, Mark Dufour의 비교에서는 3.15의 CPython 2.7 대비 평균 속도 향상이 JIT 없이 1.61배, JIT 사용 시 2.47배였으나 여전히 PyPy보다는 크게 느렸습니다.
- **PyPy 8.0.1 출시:** PyPy 8.0.1은 버퍼 메모리 누수와 C `PyObject` 연결 관련 문제를 수정했으며, 3.11 지원은 보안 이슈가 없는 한 이번 릴리스가 마지막입니다.
- **패키징 거버넌스와 공급망 보안:** PEP 772에 따라 첫 Python Packaging Council 위원 5명이 선출되어 회의를 시작했고, PyPI 보안 작업과 함께 바이너리 wheel이 공급망 공격에 갖는 의미를 분석하는 글도 나왔습니다.
- **실무 사례와 언어 비교:** 한 개발자는 AI를 PDF 송장 필드 추출에만 쓰고 계산·검증은 테스트된 Python 코드와 사람의 승인으로 처리하는 장부 시스템을 공개했고, JetBrains 조사에서는 Go로 이전한 팀들도 AI·데이터 작업에는 Python을 계속 함께 쓰는 것으로 나타났습니다.
