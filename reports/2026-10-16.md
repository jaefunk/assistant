## AI / LLM

- **음성·에이전트 제품 출시:** xAI는 음성-음성 모델 Grok Voice 3.0을 기존과 같은 분당 0.08달러에 출시했으며 Artificial Analysis 지수에서 86.9점으로 OpenAI GPT-Live-1(83.2점)보다 높은 점수를 기록했고, Rivian은 자사 전기차에 AI 에이전트를 탑재할 계획을 밝혔습니다.

## Python

- Python 3.15.0이 정식 출시되어 기본 텍스트 인코딩이 UTF-8로 바뀌고 선택형 지연 임포트와 `frozendict`·`sentinel` 내장 타입이 추가되었으며, 이어서 3.16.0 알파 1도 공개되었습니다(정식 출시 2027년 10월 5일 예정).
- 3.15의 실험적 JIT 성능을 측정한 글들이 나왔는데, Miguel Grinberg는 피보나치·버블 정렬 기준 JIT 빌드가 약 20~28% 빨랐다고 보고했고, Mark Dufour는 8개 프로그램에서 CPython 2.7 대비 평균 속도 향상이 JIT 없이 1.61배, JIT 사용 시 2.47배였다고 밝혔습니다.
- 다른 구현체와 도구도 새 버전을 냈는데, PyPy는 메모리 누수 등을 고친 v8.0.1을 내놓으며 이번이 3.11을 지원하는 마지막 릴리스라고 밝혔고, Polars 2.0과 Django 보안 릴리스가 나왔으며, uv 0.13.0은 Python 3.15를 기본값으로 정했습니다.
- 패키징 분야에서는 PEP 772에 따라 첫 Python Packaging Council 위원 5명이 선출되어 회의를 시작했고, PyPI 바이너리 휠과 공급망 공격의 관계를 다룬 분석 글도 나왔습니다.
- AI 활용 사례로는 PDF 송장의 필드 추출에만 LLM을 쓰고 계산과 검증은 테스트를 갖춘 Python 코드와 사람의 승인으로 처리한 개인 회계 시스템이 소개되었고, JetBrains 2026 설문은 Go와 Python 개발자의 AI 통합 구현 비율이 46%와 44%로 비슷하다고 보고했습니다.
